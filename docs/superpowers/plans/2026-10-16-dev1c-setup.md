# dev1c-setup Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the launch scripts, `.env` and `SETUP.md` with one binary, `dev1c-setup`, that installs the environment from a kit, knows its state by facts and ends with checks; and prepare the image for `1c-connect` (stage 1 of the spec).

**Architecture:** A Cargo workspace `setup/` with a `common` crate (operations with state and plan, kit, docker wrapper, checksums, events) copied in spirit from `C:\dev\volt-setup`, and a `dev1c-setup` binary: `dev1c.toml` → `Cfg` → operations (`env`, `image`, `volumes`, `model`, `container`, `services`) → checks that write `last-check.txt`. CI builds the binaries, installs the image through `dev1c-setup` instead of shell checks, and packs two kits.

**Tech Stack:** Rust 2021, `clap` 4 (derive), `serde` + `toml`, `anyhow`, `sha2`, `reqwest` (blocking, rustls on Linux / native-tls on Windows). No Tauri in this plan (windows are stage 4). Shell: POSIX `sh` for the image, GitHub Actions for builds.

**Spec:** `docs/superpowers/specs/2026-10-16-setup-binaries-design.md` (and, for the image, `2026-10-13-dev1c-image-design.md`).

## Global Constraints

- Every user-facing string of the binaries and of `dev1c.toml` is Russian; code comments and commit messages are English (repository rule from `README.md`).
- Nothing about 1C bases on the server side: no `[base]` in `dev1c.toml`, no `MCP_1C_*` anywhere in the image or the binary.
- Workstation ports by convention: `dev1` → 7771 (`1c`), 7781 (`vrunner`), 7791 (web client of the base); `dev2` → 7772/7782/7792; `dev3` → 7773/7783/7793. Nothing is configurable here.
- Container contract unchanged: name `dev1c`, volumes `dev1c-home`, `dev1c-gitea`, `dev1c-models`, ports `PORT..PORT+3` → `3389, 3000, 8080, 2022`, `--init`, `--shm-size 2g`, `--cap-add SYS_ADMIN`, `--security-opt seccomp=unconfined`, `--security-opt apparmor=unconfined`, `--device /dev/fuse`, `--restart unless-stopped`.
- Every modifying command obeys `--dry-run`; state probes run even under `--dry-run`.
- Model: in this iteration the model is served remotely (`[model] url`); the `model` operation exists but CI never exercises the file path.
- Line endings: files that land in the image are LF; `.gitattributes` already handles `*.sh`. The `sed` CRLF step in the Dockerfile touches text files only.
- Commits use the identity `OktaPlus <oktacoder@gmail.com>` via `GIT_AUTHOR_*`/`GIT_COMMITTER_*` exported in the same shell call (no global git config on this machine) and end with `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>`.

## Review Focus

1. **`dev1c.toml` with both `file` and `url` in `[model]`, or `url` without `name`:** `Cfg::validate` must refuse with a Russian message naming the field, not start a container with half an environment. Test in Task 3.
2. **`docker run` fails half-way (ports taken):** the `container` operation must surface the engine's last lines and the hint `change port=4000`, and `status` afterwards must show `не сделано`, not `разошлось`. Test of `run_args` plus the failure text in Task 4.
3. **An existing container from an older image or with other ports:** `container.state` must say `разошлось` with both values, and `install` must recreate it (rm -f, run) without touching volumes. Test in Task 4 (`drift_of` pure function).
4. **`check` when the tunnel is not up:** the workstation-port facts must be informational (`ok: true`, text «туннель dev1 не поднят»), never a failure that makes `install` exit 1. Test in Task 5.
5. **Settings substitution for the tunnel account `dev` and for unknown homes:** the entrypoint must leave placeholders alone where the user is not `dev1..dev3`, and must not break the JSON. Test in Task 1 (shell test on a scratch copy).

```sh
    # (mcp-1c) and 7781 (vrunner-mcp), dev2 -> 7772/7782, dev3 -> 7773/7783.
    # Fixed by convention so that neither side needs a parameter; 1c-connect

    # a port fails loudly instead of binding somebody else's tunnel.

                -e "s|WORKSTATION_1C_PORT_PLACEHOLDER|$((7770 + n))|" \
                -e "s|WORKSTATION_VRUNNER_PORT_PLACEHOLDER|$((7780 + n))|" \
                "$cfg"
            ;;
    esac
```

Create `config/test-entrypoint-ports.sh`:

```sh
#!/bin/sh
# The tunnel ports in Zed settings are substituted per workstation and left
# alone everywhere else. Runs inside the started container: by then the
# entrypoint has laid out every home.
set -eu

fail() { echo "FAIL: $*" >&2; exit 1; }

for n in 1 2 3; do
    cfg=/home/dev$n/.config/zed/settings.json
    grep -q "\"args\": \[\"localhost\", \"777$n\"\]" "$cfg" \
        || fail "dev$n: mcp-1c port 777$n not in $cfg"
    grep -q "\"args\": \[\"localhost\", \"778$n\"\]" "$cfg" \
        || fail "dev$n: vrunner port 778$n not in $cfg"
    grep -q PLACEHOLDER "$cfg" | grep -q WORKSTATION && fail "dev$n: placeholder left"
    # Still valid JSON after sed: Zed ignores a broken file silently.
    python3 -c "import json,re,sys; json.loads(re.sub(r'^\s*//.*$', '', open('$cfg').read(), flags=re.M))" \
        || fail "dev$n: settings.json is not valid JSON after substitution"
done

# The tunnel account has a home too, and no workstation number.
if [ -f /home/dev/.config/zed/settings.json ]; then
    grep -q WORKSTATION_1C_PORT_PLACEHOLDER /home/dev/.config/zed/settings.json \
        || fail "dev: placeholder was substituted for a non-workstation account"
fi

grep -q '^    PermitListen localhost:7771 .*localhost:7793$' /etc/ssh/sshd_config.d/dev1c.conf \
    || fail "sshd: PermitListen for the nine workstation ports is missing"
# sshd must accept its own config, otherwise it never started and the whole
# tunnel scheme is dead without a word.
pgrep -x sshd >/dev/null || fail "sshd is not running: check /etc/ssh/sshd_config.d/dev1c.conf"

echo "ok: workstation ports substituted (7771-7773, 7781-7783), sshd restricted to 777N/778N/779N"
```

```rust
//! Каркас двух установщиков: dev1c-setup (машина с Docker) и 1c-connect
//! (машина с 1С). Скопирован по образцу volt-setup: вся логика в операциях,
//! окно и командная строка — тонкие оболочки над ними.
//!
//! Движок ничего не печатает сам: он отдаёт события (`Event`) наблюдателю.
//! CLI печатает их в терминал, окно — рисует в списке шагов.

pub mod docker;
pub mod integrity;
pub mod kit;
pub mod op;
pub mod run;

use std::sync::Arc;

/// Что программа делает прямо сейчас.
#[derive(Debug, Clone)]
pub enum Event {
    /// Хорошая новость.
    Ok(String),
    /// Не ошибка, но человеку стоит знать.
    Warn(String),
    /// Ошибка, из-за которой шаг не сделан.
    Fail(String),
    /// Просто строка (адреса, пояснения, план).
    Say(String),
    /// Команда, которую сейчас выполняем (в режиме показа — только печатаем).
    Command(String),
    /// Сырой вывод внешней программы: в терминал не идёт, живёт в журнале.
    Output { command: String, text: String },
}

/// Куда движок отдаёт события.
pub type Sink = Arc<dyn Fn(Event) + Send + Sync>;

/// Как спрашивать у человека. В CLI — чтение строки, в окне — диалог,
/// в режиме `--yes` — всегда значение по умолчанию.
pub trait Prompt: Send + Sync {
    fn ask(&self, question: &str, default: &str) -> String;
    fn confirm(&self, question: &str, default_yes: bool) -> bool;
}

/// Согласие на всё: значения по умолчанию без вопросов (`--yes`).
pub struct AlwaysDefault;

impl Prompt for AlwaysDefault {
    fn ask(&self, _question: &str, default: &str) -> String {
        default.to_string()
    }
    fn confirm(&self, _question: &str, default_yes: bool) -> bool {
        default_yes
    }
}

/// Вопросы с клавиатуры.
pub struct StdinPrompt;

impl Prompt for StdinPrompt {
    fn ask(&self, question: &str, default: &str) -> String {
        use std::io::Write;
        print!("{question} [{default}]: ");
        let _ = std::io::stdout().flush();
        let mut s = String::new();
        let _ = std::io::stdin().read_line(&mut s);
        let s = s.trim();
        if s.is_empty() { default.to_string() } else { s.to_string() }
    }
    fn confirm(&self, question: &str, default_yes: bool) -> bool {
        let d = if default_yes { "Д/н" } else { "д/Н" };
        let a = self.ask(question, d).to_lowercase();
        match a.as_str() {
            "д" | "да" | "y" | "yes" => true,
            "н" | "нет" | "n" | "no" => false,
            _ => default_yes,
        }
    }
}

/// То, что операции и обёртки над командами спрашивают у контекста прогона.
/// Каждая программа держит свой контекст (со своей конфигурацией) и реализует
/// это для него.
pub trait Runner: Sync {
    fn dry_run(&self) -> bool;
    fn sink(&self) -> &Sink;
    fn kit(&self) -> &kit::Kit;
    /// Имя движка контейнеров: `docker` или `podman`.
    fn engine(&self) -> String {
        "docker".into()
    }
    fn emit(&self, e: Event) {
        (self.sink())(e);
    }
    fn ok(&self, t: impl Into<String>) {
        self.emit(Event::Ok(t.into()));
    }
    fn warn(&self, t: impl Into<String>) {
        self.emit(Event::Warn(t.into()));
    }
    fn fail(&self, t: impl Into<String>) {
        self.emit(Event::Fail(t.into()));
    }
    fn say(&self, t: impl Into<String>) {
        self.emit(Event::Say(t.into()));
    }
}
```

- [ ] **Step 3: `op.rs` — copy of volt-setup with a generic context**

`setup/common/src/op.rs`:

```rust
//! Операция — единица работы над машиной.
//!
//! Всё, что умеет установщик, выражено операциями: у каждой есть состояние,
//! план, применение и откат. Из этого получаются установка (применить то, чего
//! не хватает), правка (применить только разошедшееся), очистка (откатить в
//! обратном порядке) и показ состояния (спросить и ничего не делать).

use crate::Runner;
use anyhow::Result;

/// В каком состоянии параметр машины.
#[derive(Debug, Clone, PartialEq)]
pub enum OpState {
    /// Сделано и совпадает с желаемым.
    Done(String),
    /// Ещё не сделано.
    Missing,
    /// Сделано, но не так: на машине одно, в комплекте другое.
    Drifted { from: String, to: String },
    /// Сделать нельзя, и вот почему (нет данных, нет прав, не запущен движок).
    Blocked(String),
}

impl OpState {
    pub fn needs_work(&self) -> bool {
        matches!(self, OpState::Missing | OpState::Drifted { .. })
    }
    /// Короткая подпись для списка операций.
    pub fn label(&self) -> String {
        match self {
            OpState::Done(v) if v.is_empty() => "сделано".into(),
            OpState::Done(v) if v.chars().count() > 40 => {
                format!("сделано: {}…", v.chars().take(36).collect::<String>())
            }
            OpState::Done(v) => format!("сделано: {v}"),
            OpState::Missing => "не сделано".into(),
            OpState::Drifted { from, to } => format!("разошлось: {from} -> {to}"),
            OpState::Blocked(why) => format!("нельзя: {why}"),
        }
    }
}

/// Строка плана: что именно произойдёт. Это же печатает `--dry-run`.
#[derive(Debug, Clone)]
pub struct Action(pub String);

impl Action {
    pub fn new(t: impl Into<String>) -> Self {
        Action(t.into())
    }
}

/// Уровни очистки: каждый следующий включает предыдущий.
#[derive(Debug, Clone, Copy, PartialEq, Eq, PartialOrd, Ord)]
pub enum CleanLevel {
    /// Снять контейнер. Данные на месте.
    Stack,
    /// Удалить и данные: тома.
    Data,
}

pub trait Op<X: Runner>: Sync {
    /// Устойчивый идентификатор: `image`, `container`. По нему работает `--only`.
    fn id(&self) -> &'static str;
    /// Название для человека.
    fn title(&self) -> &'static str;
    /// Состояние, без изменений на машине.
    fn state(&self, ctx: &X) -> OpState;
    /// Что будет сделано.
    fn plan(&self, ctx: &X) -> Vec<Action>;
    /// Сделать. Обязано быть идемпотентным: повторный вызов ничего не портит.
    fn apply(&self, ctx: &X) -> Result<()>;
    /// Чем это снести. `None` — откатывать нечего.
    fn revert(&self, _ctx: &X, _level: CleanLevel) -> Option<Vec<Action>> {
        None
    }
    /// Сделать откат. Уровень передаётся, потому что одна и та же операция на
    /// разных уровнях сносится по-разному: контейнер снимается всегда, тома
    /// удаляются только на уровне данных.
    fn revert_apply(&self, _ctx: &X, _level: CleanLevel) -> Result<()> {
        Ok(())
    }
    /// Выполняется при каждой установке (проверки окружения). В списке
    /// состояния у неё нет «сделано»: она ничего не оставляет после себя.
    fn always_run(&self) -> bool {
        false
    }
}

}
```

```rust
//! Разговор с движком контейнеров. Имя движка — параметр контекста (`docker`
//! или `podman`). Запуск всегда через `Command` с отдельными аргументами: нет

use crate::{Event, Runner};
use anyhow::{Context, Result};
use std::process::Command;

pub struct Out {
    pub code: i32,
    pub text: String,
}

impl Out {
    pub fn ok(&self) -> bool {
        self.code == 0
    }
    /// Последние непустые строки вывода — для сообщений об ошибке.
    pub fn tail(&self, n: usize) -> Vec<String> {
        let lines: Vec<&str> = self.text.lines().map(|l| l.trim_end()).filter(|l| !l.is_empty()).collect();
        lines[lines.len().saturating_sub(n)..].iter().map(|s| s.to_string()).collect()
    }
}

/// Запуск без своего окна консоли: без этого Windows рисует чёрное окно на
/// каждый вызов из оконной программы.
pub fn quiet(mut cmd: Command) -> Command {
    #[cfg(windows)]
    {
        use std::os::windows::process::CommandExt;
        const CREATE_NO_WINDOW: u32 = 0x0800_0000;
        cmd.creation_flags(CREATE_NO_WINDOW);
    }
    cmd
}

/// Запустить произвольную программу и собрать её вывод (stdout и stderr вместе).
pub fn exec<X: Runner>(ctx: &X, program: &str, args: &[&str]) -> Result<Out> {
    exec_inner(ctx, program, args, false)
}

/// Спросить машину о состоянии. Выполняется ВСЕГДА, в том числе в режиме
/// показа: иначе `--dry-run` докладывал бы, что ничего не установлено.
pub fn probe<X: Runner>(ctx: &X, program: &str, args: &[&str]) -> Result<Out> {
    exec_inner(ctx, program, args, true)
}

fn exec_inner<X: Runner>(ctx: &X, program: &str, args: &[&str], read_only: bool) -> Result<Out> {
    let shown = format!("{program} {}", args.join(" "));
    ctx.emit(Event::Command(shown.clone()));
    if ctx.dry_run() && !read_only {
        return Ok(Out { code: 0, text: String::new() });
    }
    let output = quiet(Command::new(program))
        .args(args)
        .output()
        .with_context(|| format!("не удалось запустить {program}"))?;
    let mut text = String::from_utf8_lossy(&output.stdout).into_owned();
    text.push_str(&String::from_utf8_lossy(&output.stderr));
    ctx.emit(Event::Output { command: shown, text: text.clone() });
    Ok(Out { code: output.status.code().unwrap_or(-1), text })
}
```

```rust
//! Целость комплекта: сверка файлов с контрольными суммами.
//!
//! Комплект едет к заказчику архивом, копируется на флешку и переносится по
//! сети; любой шаг способен обрезать файл. Сверка называет виновника до того,
//! как на машине что-то изменилось.

use crate::kit::{write_text, Kit};
use anyhow::{Context, Result};
use sha2::{Digest, Sha256};
use std::path::{Path, PathBuf};

pub const LIST: &str = "checksums.txt";

#[derive(Debug, Clone, PartialEq)]
pub enum FileState {
    Ok,
    Missing,
    Changed,
}

#[derive(Debug, Clone)]
pub struct Entry {
    pub path: String,
    pub state: FileState,
}

#[derive(Debug, Default)]
pub struct Report {
    pub entries: Vec<Entry>,
}

impl Report {
    pub fn ok(&self) -> bool {
        self.entries.iter().all(|e| e.state == FileState::Ok)
    }
}

pub fn sha256_file(path: &Path) -> Result<String> {
    let mut f = std::fs::File::open(path).with_context(|| format!("не открыть {}", path.display()))?;
    let mut h = Sha256::new();
    std::io::copy(&mut f, &mut h)?;
    Ok(format!("{:x}", h.finalize()))
}

/// Что входит в список: всё, кроме самого списка и того, что программа пишет сама.
fn listed(rel: &str) -> bool {
    !(rel == LIST || rel.ends_with(".log") || rel == "install.state" || rel == "last-check.txt")
}

fn walk(dir: &Path, root: &Path, out: &mut Vec<PathBuf>) -> Result<()> {
    for e in std::fs::read_dir(dir).with_context(|| format!("не прочитать {}", dir.display()))? {
        let p = e?.path();
        if p.is_dir() {
            walk(&p, root, out)?;
        } else {
            out.push(p);
        }
    }
    Ok(())
}

fn rel(root: &Path, p: &Path) -> String {
    p.strip_prefix(root).unwrap_or(p).to_string_lossy().replace('\\', "/")
}

/// Собрать список сумм (при сборке поставки). Возвращает число файлов.
pub fn write_list(kit: &Kit, mut progress: impl FnMut(&str)) -> Result<usize> {
    let mut files = Vec::new();
    walk(&kit.root, &kit.root, &mut files)?;
    files.sort();
    let mut lines = Vec::new();
    for p in files {
        let r = rel(&kit.root, &p);
        if !listed(&r) {
            continue;
        }
        progress(&r);
        lines.push(format!("{}  {}", sha256_file(&p)?, r));
    }
    write_text(&kit.path(LIST), &(lines.join("\n") + "\n"))?;
    Ok(lines.len())
}

/// Сверить комплект со списком.
pub fn verify(kit: &Kit, mut progress: impl FnMut(usize, usize, &str)) -> Result<Report> {
    let text = std::fs::read_to_string(kit.path(LIST)).context("в комплекте нет checksums.txt")?;
    let items: Vec<(String, String)> = text
        .lines()
        .filter_map(|l| l.split_once("  "))
        .map(|(h, p)| (h.to_string(), p.to_string()))
        .collect();
    let mut report = Report::default();
    for (i, (hash, path)) in items.iter().enumerate() {
        progress(i + 1, items.len(), path);
        let p = kit.path(path);
        let state = if !p.exists() {
            FileState::Missing
        } else if sha256_file(&p)? == *hash {
            FileState::Ok
        } else {
            FileState::Changed
        };
        report.entries.push(Entry { path: path.clone(), state });
    }
    Ok(report)
}
```

```rust
//! Прогон списка операций: установка, состояние, очистка. Печатает через
//! `ctx.say`, поэтому одинаково работает из терминала и из окна.

use crate::op::{CleanLevel, Op, OpState};
use crate::Runner;
use anyhow::Result;

/// Применить операции. `only` — одна по идентификатору; `changes_only` —
/// только разошедшиеся (команда `change`). Возвращает число тронутых.
pub fn apply_all<X: Runner>(ctx: &X, ops: &[Box<dyn Op<X>>], only: Option<&str>, changes_only: bool) -> Result<usize> {
    if let Some(id) = only {
        anyhow::ensure!(ops.iter().any(|o| o.id() == id), "нет операции {id}");
    }
    let mut touched = 0;
    for op in ops {
        if only.is_some_and(|id| op.id() != id) {
            continue;
        }
        if changes_only && op.always_run() {
            continue;
        }
        let st = op.state(ctx);
        if changes_only && !st.needs_work() {
            continue;
        }
        match &st {
            OpState::Done(_) if only.is_none() && !op.always_run() => {
                ctx.say(format!("  [ ok ] {:<12} уже сделано", op.id()));
                continue;
            }
            OpState::Blocked(why) => {
                ctx.say(format!("  [ -- ] {:<12} пропущено: {why}", op.id()));
                continue;
            }
            _ => {}
        }
        ctx.say("");
        ctx.say(format!("== {} — {}", op.id(), op.title()));
        if let OpState::Drifted { from, to } = &st {
            ctx.say(format!("   было:   {from}"));
            ctx.say(format!("   станет: {to}"));
        }
        for a in op.plan(ctx) {
            ctx.say(format!("   · {}", a.0));
        }
        touched += 1;
        if ctx.dry_run() {
            continue;
        }
        op.apply(ctx)?;
    }
    ctx.say("");
    if ctx.dry_run() {
        ctx.say("План напечатан, на машине ничего не менялось.");
    } else if touched == 0 {
        ctx.say("Менять нечего: всё уже так, как задано.");
    } else {
        ctx.say("Готово.");
    }
    Ok(touched)
}

/// Состояние каждой операции, без изменений.
pub fn status<X: Runner>(ctx: &X, ops: &[Box<dyn Op<X>>]) -> Vec<(String, String, OpState)> {
    ops.iter()
        .filter(|o| !o.always_run())
        .map(|o| (o.id().to_string(), o.title().to_string(), o.state(ctx)))
        .collect()
}

/// Откат в обратном порядке. План печатается всегда; выполнение — после
/// подтверждения, которое спрашивает вызывающий.
pub fn clean_plan<X: Runner>(ctx: &X, ops: &[Box<dyn Op<X>>], level: CleanLevel) -> Vec<(String, Vec<String>)> {
    ops.iter()
        .rev()
        .filter_map(|o| o.revert(ctx, level).map(|acts| (o.id().to_string(), acts.into_iter().map(|a| a.0).collect())))
        .collect()
}

pub fn clean_apply<X: Runner>(ctx: &X, ops: &[Box<dyn Op<X>>], level: CleanLevel) -> Result<()> {
    for o in ops.iter().rev() {
        if o.revert(ctx, level).is_some() && !ctx.dry_run() {
            o.revert_apply(ctx, level)?;
        }
    }
    Ok(())
}
```

```rust
pub struct Cfg {
    pub server: Server,
    pub model: Model,
}

#[derive(Debug, Clone, PartialEq, Serialize, Deserialize)]
#[serde(default, deny_unknown_fields)]
pub struct Server {
    pub name: String,
    pub port: u16,
    pub memory: String,
    pub gpu: bool,
    pub engine: String,
}

#[derive(Debug, Clone, PartialEq, Serialize, Deserialize)]
#[serde(default, deny_unknown_fields)]
pub struct Model {
    pub file: String,
    pub url: String,
    pub key: String,
    pub name: String,
}

impl Default for Server {
    fn default() -> Self {
        Self { name: "dev1c".into(), port: 3390, memory: "24g".into(), gpu: true, engine: "docker".into() }
    }
}

impl Default for Model {
    fn default() -> Self {
        Self { file: String::new(), url: String::new(), key: String::new(), name: String::new() }
    }
}

impl Default for Cfg {
    fn default() -> Self {
        Self { server: Server::default(), model: Model::default() }
    }
}

pub const FILE: &str = "dev1c.toml";

impl Cfg {
    /// Читает `dev1c.toml` из комплекта. Нет файла — значения по умолчанию,
    /// и `status` скажет об этом.
    pub fn load(kit: &Kit) -> Result<Cfg> {
        let p = kit.path(FILE);
        if !p.exists() {
            return Ok(Cfg::default());
        }
        let text = std::fs::read_to_string(&p).with_context(|| format!("не прочитать {}", p.display()))?;
        let cfg: Cfg = toml::from_str(&text).with_context(|| format!("{FILE}: ошибка в файле параметров"))?;
        cfg.validate()?;
        Ok(cfg)
    }

    /// Ошибка называет поле и что с ним делать.
    pub fn validate(&self) -> Result<()> {
        let m = &self.model;
        anyhow::ensure!(
            m.file.is_empty() || m.url.is_empty(),
            "[model]: задано и file, и url — оставьте одно: файл в комплекте или удалённый сервер"
        );
        if !m.url.is_empty() {
            anyhow::ensure!(!m.name.is_empty(), "[model]: для удалённого сервера нужно name — имя модели, как сервер его называет");
            anyhow::ensure!(!m.key.is_empty(), "[model]: для удалённого сервера нужно key — ключ доступа");
        }
        anyhow::ensure!(self.server.port >= 1024 && self.server.port <= 65532, "[server]: port должен быть от 1024 до 65532 (нужны четыре порта подряд)");
        anyhow::ensure!(matches!(self.server.engine.as_str(), "docker" | "podman"), "[server]: engine — docker или podman");
        Ok(())
    }

    /// RDP, Gitea, модель, SSH.
    pub fn ports(&self) -> [u16; 4] {
        let p = self.server.port;
        [p, p + 1, p + 2, p + 3]
    }

    /// Что уходит в контейнер через -e. Локальная модель не требует ничего:
    /// entrypoint находит файл в томе сам.
    pub fn container_env(&self) -> Vec<(String, String)> {
        let m = &self.model;
        if m.url.is_empty() {
            return Vec::new();
        }
        vec![
            ("CUSTOM_API_URL".into(), m.url.clone()),
            ("CUSTOM_API_KEY".into(), m.key.clone()),
            ("CUSTOM_MODEL".into(), m.name.clone()),
            ("LLAMA_ENABLED".into(), "0".into()),
        ]
    }

    pub fn volume(&self, suffix: &str) -> String {
        format!("{}-{}", self.server.name, suffix)
    }

    pub fn image(&self) -> String {
        "oktaplus/dev1c:latest".into()
    }
}
```

```rust
/// Аргументы `docker run`. Те же, что были в dev1c.ps1, по тем же причинам:
/// --init — настоящий init как PID 1, иначе xrdp не жнёт сирот; SYS_ADMIN и
/// seccomp/apparmor unconfined — xrdp-sesman открывает PAM-сессию; /dev/fuse —
/// проброс дисков Windows по RDP идёт через FUSE; shm 2g — браузер и Zed.
pub fn run_args(cfg: &Cfg) -> Vec<String> {
    let s = |x: &str| x.to_string();
    let [rdp, gitea, model, ssh] = cfg.ports();
    let mut a = vec![
        s("run"), s("-d"), s("--name"), cfg.server.name.clone(), s("--restart"), s("unless-stopped"), s("--init"),
        s("-p"), format!("{rdp}:3389"), s("-p"), format!("{gitea}:3000"), s("-p"), format!("{model}:8080"), s("-p"), format!("{ssh}:2022"),
        s("--shm-size"), s("2g"), s("--memory"), cfg.server.memory.clone(),
        s("--cap-add"), s("SYS_ADMIN"), s("--security-opt"), s("seccomp=unconfined"), s("--security-opt"), s("apparmor=unconfined"),
        s("--device"), s("/dev/fuse"),
        s("-v"), format!("{}:/home", cfg.volume("home")),
        s("-v"), format!("{}:/var/lib/gitea", cfg.volume("gitea")),
        s("-v"), format!("{}:/opt/models", cfg.volume("models")),
    ];
    if cfg.server.gpu {
        // Флаги GPU у движков разные.
        if cfg.server.engine == "podman" {
            a.extend([s("--device"), s("nvidia.com/gpu=all")]);
        } else {
            a.extend([s("--gpus"), s("all")]);
        }
    }
    for (k, v) in cfg.container_env() {
        a.extend([s("-e"), format!("{k}={v}")]);
    }
    a.push(cfg.image());
    a
}

/// Чем работающий контейнер отличается от заданного: образ, первый порт,
/// переменные. `None` — ничем. Чистая функция ради теста; значения ей даёт
/// `docker inspect`.
pub fn drift_of(cfg: &Cfg, image: &str, first_port: &str, env: &[String]) -> Option<(String, String)> {
    if image != cfg.image() {
        return Some((format!("образ {image}"), format!("образ {}", cfg.image())));
    }
    let want_port = cfg.server.port.to_string();
    if first_port != want_port {
        return Some((format!("порт {first_port}"), format!("порт {want_port}")));
    }
    for (k, v) in cfg.container_env() {
        let want = format!("{k}={v}");
        let have = env.iter().find(|e| e.starts_with(&format!("{k}=")));
        if have != Some(&want) {
            let have = have.cloned().unwrap_or_else(|| format!("{k} не задан"));
            // Ключ в тексте состояния не показываем.
            let hide = |s: String| if k == "CUSTOM_API_KEY" { format!("{k}=…") } else { s };
            return Some((hide(have), hide(want)));
        }
    }
    None
}
```

```rust
struct Env;
impl Op<Ctx> for Env {
    fn id(&self) -> &'static str { "env" }
    fn title(&self) -> &'static str { "Окружение" }
    fn always_run(&self) -> bool { true }
    fn state(&self, ctx: &Ctx) -> OpState {
        if !docker::available(ctx) {
            return OpState::Blocked(format!("{} не отвечает: запустите Docker Desktop или установите движок", ctx.engine()));
        }
        OpState::Missing
    }
    fn plan(&self, ctx: &Ctx) -> Vec<Action> {
        vec![Action::new(format!("проверить движок, файл параметров и порты {}–{}", ctx.cfg.ports()[0], ctx.cfg.ports()[3]))]
    }
    fn apply(&self, ctx: &Ctx) -> Result<()> {
        match docker::version(ctx) {
            Some(v) => ctx.ok(format!("{} {v}", ctx.engine())),
            None => anyhow::bail!("{} не отвечает", ctx.engine()),
        }
        if !ctx.kit.path(crate::cfg::FILE).exists() {
            ctx.warn(format!("{} нет в комплекте — действуют значения по умолчанию", crate::cfg::FILE));
        }
        // Порт занят не нашим контейнером — установка упрётся в docker run с
        // невнятной ошибкой; лучше сказать здесь и назвать выход.
        let ours = docker::container_state(ctx, &ctx.cfg.server.name) == "running";
        for p in ctx.cfg.ports() {
            if !ours && std::net::TcpListener::bind(("0.0.0.0", p)).is_err() {
                anyhow::bail!("порт {p} занят другой программой — задайте другой блок: dev1c-setup change port=4000");
            }
        }
        ctx.ok(format!("порты {}–{} свободны или наши", ctx.cfg.ports()[0], ctx.cfg.ports()[3]));
        Ok(())
    }
}

struct Image;
impl Op<Ctx> for Image {
    fn id(&self) -> &'static str { "image" }
    fn title(&self) -> &'static str { "Образ среды" }
    fn state(&self, ctx: &Ctx) -> OpState {
        if docker::image_loaded(ctx, &ctx.cfg.image()) {
            return OpState::Done(ctx.cfg.image());
        }
        if !ctx.kit.path("dev1c-image.tar.gz").exists() {
            return OpState::Blocked("в комплекте нет dev1c-image.tar.gz".into());
        }
        OpState::Missing
    }
    fn plan(&self, ctx: &Ctx) -> Vec<Action> {
        vec![Action::new(format!("{} load -i dev1c-image.tar.gz (несколько минут)", ctx.engine()))]
    }
    fn apply(&self, ctx: &Ctx) -> Result<()> {
        let archive = ctx.kit.path("dev1c-image.tar.gz");
        let o = docker::load_image(ctx, &archive.to_string_lossy())?;
        anyhow::ensure!(o.ok(), "образ не загрузился: {}", o.tail(3).join(" "));
        ctx.ok("образ загружен");
        Ok(())
    }
    fn revert(&self, ctx: &Ctx, level: CleanLevel) -> Option<Vec<Action>> {
        (level >= CleanLevel::Data).then(|| vec![Action::new(format!("удалить образ {}", ctx.cfg.image()))])
    }
    fn revert_apply(&self, ctx: &Ctx, level: CleanLevel) -> Result<()> {
        if level >= CleanLevel::Data {
            let _ = docker::run(ctx, &["rmi", &ctx.cfg.image()]);
        }
        Ok(())
    }
}

struct Volumes;
impl Op<Ctx> for Volumes {
    fn id(&self) -> &'static str { "volumes" }
    fn title(&self) -> &'static str { "Тома данных" }
    fn state(&self, ctx: &Ctx) -> OpState {
        let missing: Vec<String> = ["home", "gitea", "models"].iter().map(|s| ctx.cfg.volume(s)).filter(|v| !docker::volume_exists(ctx, v)).collect();
        if missing.is_empty() { OpState::Done("home, gitea, models".into()) } else { OpState::Missing }
    }
    fn plan(&self, ctx: &Ctx) -> Vec<Action> {
        ["home", "gitea", "models"].iter().map(|s| Action::new(format!("{} volume create {}", ctx.engine(), ctx.cfg.volume(s)))).collect()
    }
    fn apply(&self, ctx: &Ctx) -> Result<()> {
        for s in ["home", "gitea", "models"] {
            let v = ctx.cfg.volume(s);
            if !docker::volume_exists(ctx, &v) {
                let o = docker::run(ctx, &["volume", "create", &v])?;
                anyhow::ensure!(o.ok(), "том {v} не создался: {}", o.tail(2).join(" "));
            }
        }
        ctx.ok("тома на месте");
        Ok(())
    }
    fn revert(&self, ctx: &Ctx, level: CleanLevel) -> Option<Vec<Action>> {

struct Model;
impl Op<Ctx> for Model {
    fn id(&self) -> &'static str { "model" }
    fn title(&self) -> &'static str { "Файл модели" }
    fn state(&self, ctx: &Ctx) -> OpState {
        let f = &ctx.cfg.model.file;
        if f.is_empty() {
            return if ctx.cfg.model.url.is_empty() {
                OpState::Blocked("модель не задана: ни file, ни url в [model] — агент будет молчать".into())
            } else {
                OpState::Done(format!("удалённая: {}", ctx.cfg.model.name))
            };
        }
        let src = ctx.kit.path(f);
        let Ok(meta) = std::fs::metadata(&src) else {
            return OpState::Blocked(format!("файла {f} нет в комплекте"));
        };
        let base = src.file_name().map(|n| n.to_string_lossy().to_string()).unwrap_or_default();
        if !docker::volume_exists(ctx, &ctx.cfg.volume("models")) {
            return OpState::Missing;
        }
        let o = docker::sh_in_volume_ro(ctx, &ctx.cfg.image(), &ctx.cfg.volume("models"), "/m", &format!("stat -c %s /m/{base} 2>/dev/null"));
        match o {
            Ok(o) if o.ok() && o.text.trim() == meta.len().to_string() => OpState::Done(base),
            _ => OpState::Missing,
        }
    }
    fn plan(&self, ctx: &Ctx) -> Vec<Action> {
        vec![Action::new(format!("скопировать {} в том {} (файл большой, это долго)", ctx.cfg.model.file, ctx.cfg.volume("models")))]
    }
    fn apply(&self, ctx: &Ctx) -> Result<()> {
        // Через работающий контейнер нельзя (его ещё нет), поэтому одноразовый
        // контейнер с томом и docker cp в него. Bind-mount каталога хоста не
        // используется намеренно: на Windows антивирус рвёт чтение больших файлов.
        let src = ctx.kit.path(&ctx.cfg.model.file);
        let vol = format!("{}:/m", ctx.cfg.volume("models"));
        let o = docker::run(ctx, &["create", "--name", "dev1c-model-copy", "-v", &vol, &ctx.cfg.image()])?;
        anyhow::ensure!(o.ok(), "не создать контейнер для копирования: {}", o.tail(2).join(" "));
        let dst = "dev1c-model-copy:/m/".to_string();
        let o = docker::run(ctx, &["cp", &src.to_string_lossy(), &dst]);
        let _ = docker::run(ctx, &["rm", "-f", "dev1c-model-copy"]);
        let o = o?;
        anyhow::ensure!(o.ok(), "модель не скопировалась: {}", o.tail(2).join(" "));
        ctx.ok("модель в томе");
        Ok(())
    }
}

struct Container;
impl Op<Ctx> for Container {
    fn id(&self) -> &'static str { "container" }
    fn title(&self) -> &'static str { "Контейнер среды" }
    fn state(&self, ctx: &Ctx) -> OpState {
        let name = &ctx.cfg.server.name;
        match docker::container_state(ctx, name).as_str() {
            "" => OpState::Missing,
            "running" => {
                let image = docker::inspect(ctx, name, "{{.Config.Image}}");
                let port = docker::inspect(ctx, name, "{{(index (index .HostConfig.PortBindings \"3389/tcp\") 0).HostPort}}");
                let env: Vec<String> = docker::inspect(ctx, name, "{{range .Config.Env}}{{println .}}{{end}}").lines().map(|s| s.to_string()).collect();
                match drift_of(&ctx.cfg, &image, &port, &env) {
                    None => OpState::Done(format!("работает, порты {}–{}", ctx.cfg.ports()[0], ctx.cfg.ports()[3])),
                    Some((from, to)) => OpState::Drifted { from, to },
                }
            }
            other => OpState::Drifted { from: other.to_string(), to: "running".into() },
        }
    }
    fn plan(&self, ctx: &Ctx) -> Vec<Action> {
        let mut v = Vec::new();
        if !docker::container_state(ctx, &ctx.cfg.server.name).is_empty() {
            v.push(Action::new(format!("{} rm -f {} (тома не трогаются)", ctx.engine(), ctx.cfg.server.name)));
        }
        let shown: Vec<String> = run_args(&ctx.cfg).iter().map(|a| if a.starts_with("CUSTOM_API_KEY=") { "CUSTOM_API_KEY=…".into() } else { a.clone() }).collect();
        v.push(Action::new(format!("{} {}", ctx.engine(), shown.join(" "))));
        v
    }
    fn apply(&self, ctx: &Ctx) -> Result<()> {
        let name = ctx.cfg.server.name.clone();
        let _ = docker::run(ctx, &["rm", "-f", &name]);
        let args = run_args(&ctx.cfg);
        let refs: Vec<&str> = args.iter().map(|s| s.as_str()).collect();
        let o = docker::run(ctx, &refs)?;
        anyhow::ensure!(
            o.ok(),
            "контейнер не запустился: {}\nДве обычные причины: порты {}–{} заняты (dev1c-setup change port=4000) или нет видеокарты (gpu = false в dev1c.toml)",
            o.tail(3).join(" "), ctx.cfg.ports()[0], ctx.cfg.ports()[3]
        );
        ctx.ok("контейнер запущен");
        Ok(())
    }
    fn revert(&self, ctx: &Ctx, _level: CleanLevel) -> Option<Vec<Action>> {
        Some(vec![Action::new(format!("{} rm -f {}", ctx.engine(), ctx.cfg.server.name))])
    }
    fn revert_apply(&self, ctx: &Ctx, _level: CleanLevel) -> Result<()> {
        let _ = docker::run(ctx, &["rm", "-f", &ctx.cfg.server.name]);
        ctx.ok("контейнер снят");
        Ok(())
    }
}

impl Op<Ctx> for Services {

    fn title(&self) -> &'static str { "Службы внутри" }
    fn always_run(&self) -> bool { true }
    fn state(&self, _ctx: &Ctx) -> OpState { OpState::Missing }
    fn plan(&self, ctx: &Ctx) -> Vec<Action> {
        vec![Action::new(format!("дождаться gitea, xrdp, sshd{} (до двух минут)", if ctx.cfg.model.file.is_empty() { "" } else { ", llama-server" }))]
    }

        let mut want = vec!["gitea", "xrdp", "sshd"];
        if !ctx.cfg.model.file.is_empty() { want.push("llama-server"); }
        let deadline = std::time::Instant::now() + std::time::Duration::from_secs(120);
        loop {
            let mut missing = Vec::new();
            for s in &want {
                // pgrep -x: exact name, otherwise the probe matches itself.
                let o = docker::ask(ctx, &["exec", &ctx.cfg.server.name, "pgrep", "-x", s])?;
                if !o.ok() { missing.push(*s); }

            if missing.is_empty() {
                ctx.ok(format!("работают: {}", want.join(", ")));
                return Ok(());
            }
            if std::time::Instant::now() > deadline {
                anyhow::bail!("не поднялись: {} — смотрите {} logs {}", missing.join(", "), ctx.engine(), ctx.cfg.server.name);
            }
            std::thread::sleep(std::time::Duration::from_secs(3));
        }
    }
}
```

```rust
//! и при провале — что делать. Отчёт пишется в файл: разработчик присылает

#[derive(Debug, Clone)]
pub struct Check {
    pub what: String,
    pub ok: bool,
    /// Информация, а не приговор: «туннель не поднят» — это не провал сервера.
    pub info: bool,
    pub detail: String,
    pub hint: String,
}

impl Check {
    fn pass(what: &str, detail: impl Into<String>) -> Self {
        Self { what: what.into(), ok: true, info: false, detail: detail.into(), hint: String::new() }
    }
    fn fail(what: &str, detail: impl Into<String>, hint: impl Into<String>) -> Self {
        Self { what: what.into(), ok: false, info: false, detail: detail.into(), hint: hint.into() }
    }
    fn note(what: &str, detail: impl Into<String>) -> Self {
        Self { what: what.into(), ok: true, info: true, detail: detail.into(), hint: String::new() }
    }
}

/// Сколько прошло и сколько провалено; информационные не считаются.
pub fn summary(checks: &[Check]) -> (usize, usize) {
    let failed = checks.iter().filter(|c| !c.ok).count();
    (checks.len() - failed, failed)
}

/// Текст отчёта: нумерованный список от основания к вершине.
pub fn render(version: &str, cfg_text: &str, checks: &[Check]) -> String {
    let mut s = format!("dev1c-setup {version}\n\n{cfg_text}\n");
    for (i, c) in checks.iter().enumerate() {
        let mark = if c.info { "info" } else if c.ok { " ok " } else { "FAIL" };
        s.push_str(&format!("{:>2}. [{mark}] {}: {}\n", i + 1, c.what, c.detail));
        if !c.hint.is_empty() {
            s.push_str(&format!("          → {}\n", c.hint));
        }
    }
    let (p, f) = summary(checks);
    s.push_str(&format!("\nПройдено {p}, провалено {f}.\n"));
    s
}

}
```

```rust
fn tcp_open(port: u16) -> bool {
    let addr: SocketAddr = ([127, 0, 0, 1], port).into();
    TcpStream::connect_timeout(&addr, Duration::from_secs(3)).is_ok()
}

fn ssh_banner(port: u16) -> Option<String> {
    let addr: SocketAddr = ([127, 0, 0, 1], port).into();
    let mut s = TcpStream::connect_timeout(&addr, Duration::from_secs(3)).ok()?;
    let _ = s.set_read_timeout(Some(Duration::from_secs(3)));
    let mut buf = [0u8; 64];
    let n = s.read(&mut buf).ok()?;
    Some(String::from_utf8_lossy(&buf[..n]).trim().to_string())
}

            return v;
        }
        other => {
            v.push(Check::fail("контейнер", format!("в состоянии {other}"), format!("{} logs {name}, затем dev1c-setup install", ctx.engine())));
            return v;
        }
    }
    v.push(if tcp_open(rdp) {
        Check::pass("рабочие места (RDP)", format!("порт {rdp} принимает соединение"))
    } else {

    });
    let url = format!("http://127.0.0.1:{gitea}/");
    v.push(match reqwest::blocking::Client::builder().timeout(Duration::from_secs(10)).build().and_then(|c| c.get(&url).send()) {

    } else {

    });
    v.push(if settings.contains("\"7771\"") { Check::pass("порты рабочих мест в Zed", "dev1 → 7771/7781") } else { Check::fail("порты рабочих мест в Zed", "порт 7771 не подставлен", "образ старее этой программы: обновите образ") });
    for n in 1..=3u16 {

    }
    v
}
```

```rust
}

fn make_ctx(kit: Kit, dry_run: bool, yes: bool) -> Result<Ctx> {
    let cfg = cfg::Cfg::load(&kit)?;
    // В терминал идут приговоры и строки плана; команды и их вывод — в журнал.
    let log_path = kit.cmd_log();
    let sink = Arc::new(move |e: Event| {
        let log = |line: String| {
            if let Ok(mut f) = std::fs::OpenOptions::new().create(true).append(true).open(&log_path) {
                use std::io::Write;
                let _ = writeln!(f, "{line}");
            }
        };
        match e {
            Event::Ok(t) => println!("  [ ok ] {t}"),
            Event::Warn(t) => println!("  [ !! ] {t}"),
            Event::Fail(t) => println!("  [FAIL] {t}"),
            Event::Say(t) => println!("{t}"),
            Event::Command(c) => log(format!("$ {c}")),
            Event::Output { command, text } => log(format!("# {command}\n{text}")),
        }
    });
    let prompt: Box<dyn Prompt> = if yes { Box::new(AlwaysDefault) } else { Box::new(StdinPrompt) };
    Ok(Ctx { kit, cfg, dry_run, sink, prompt })
}

fn run() -> Result<()> {
    let cli = Cli::parse();
    let kit = match &cli.kit {
        Some(p) => Kit::at(p),
        None => Kit::discover("DEV1C_KIT")?,
    };
    if let Some(Cmd::Example) = cli.cmd {
        print!("{}", cfg::EXAMPLE);
        return Ok(());
    }
    let mut ctx = make_ctx(kit, cli.dry_run, cli.yes)?;
    let ops = ops::server();
    match cli.cmd.unwrap_or(Cmd::Status) {
        Cmd::Example => unreachable!(),
        Cmd::Status => {
            println!("Комплект: {}", ctx.kit.root.display());
            println!();
            for (id, title, st) in common::run::status(&ctx, &ops) {
                println!("  {:<10} {:<20} {}", id, title, st.label());
            }
            println!();
            println!("Применить то, чего не хватает: dev1c-setup install");
        }
        Cmd::Install { only } => {
            common::run::apply_all(&ctx, &ops, only.as_deref(), false)?;
            if ctx.dry_run || only.is_some() {
                return Ok(());
            }
            println!();
            check(&ctx)?;
            let [rdp, gitea, model, ssh] = ctx.cfg.ports();
            println!();
            println!("Среда запущена:");
            println!("  Рабочие места   mstsc /v:<адрес этой машины>:{rdp}  —  dev1/dev1, dev2/dev2, dev3/dev3");
            println!("  Репозитории     http://<адрес>:{gitea}");
            println!("  Сервер модели   http://<адрес>:{model}");
            println!("  Для 1c-connect  адрес этой машины и порт {ssh}");
        }
        Cmd::Change { values } => {
            apply_changes(&mut ctx, &values)?;
            common::run::apply_all(&ctx, &ops, None, true)?;
        }
        Cmd::Check => check(&ctx)?,
        Cmd::Clean { stack, data } => {
            anyhow::ensure!(stack || data, "укажите уровень: --stack (снять контейнер) или --data (и удалить данные)");
            let level = if data { CleanLevel::Data } else { CleanLevel::Stack };
            for (id, acts) in common::run::clean_plan(&ctx, &ops, level) {
                println!("== {id}");
                for a in acts { println!("   · {a}"); }
            }
            if ctx.dry_run { println!("План напечатан, на машине ничего не менялось."); return Ok(()); }
            if data {
                let name = ctx.prompt.ask("Удалить данные: репозитории, проекты, настройки. Введите имя контейнера для подтверждения", "");
                anyhow::ensure!(name == ctx.cfg.server.name, "имя не совпало, ничего не удалено");
            }
            common::run::clean_apply(&ctx, &ops, level)?;
        }
        Cmd::Verify => {
            let r = common::integrity::verify(&ctx.kit, |i, n, p| println!("  {i}/{n} {p}"))?;
            for e in r.entries.iter().filter(|e| e.state != common::integrity::FileState::Ok) {
                println!("  [FAIL] {}: {:?}", e.path, e.state);
            }
            anyhow::ensure!(r.ok(), "комплект повреждён — скопируйте его заново");
            println!("Комплект цел.");
        }
        Cmd::Checksums => {
            let n = common::integrity::write_list(&ctx.kit, |p| println!("  {p}"))?;
            println!("Записано {n} сумм в checksums.txt");
        }
    }
    Ok(())
}

/// `port=4000 memory=16g gpu=false` → в toml комплекта. Правится файл, не
/// память: следующий запуск должен видеть новые значения как желаемые.
fn apply_changes(ctx: &mut Ctx, values: &[String]) -> Result<()> {
    anyhow::ensure!(!values.is_empty(), "что менять? Например: dev1c-setup change port=4000");
    for v in values {
        let (k, val) = v.split_once('=').with_context(|| format!("ожидалось ключ=значение, получено {v}"))?;
        match k {
            "port" => ctx.cfg.server.port = val.parse().context("port — число")?,
            "memory" => ctx.cfg.server.memory = val.into(),
            "gpu" => ctx.cfg.server.gpu = matches!(val, "true" | "да" | "1"),
            "engine" => ctx.cfg.server.engine = val.into(),
            "model.url" => ctx.cfg.model.url = val.into(),
            "model.key" => ctx.cfg.model.key = val.into(),
            "model.name" => ctx.cfg.model.name = val.into(),
            "model.file" => ctx.cfg.model.file = val.into(),
            other => anyhow::bail!("неизвестный параметр {other}; есть: port, memory, gpu, engine, model.url, model.key, model.name, model.file"),
        }
    }
    ctx.cfg.validate()?;
    if !ctx.dry_run {
        common::kit::write_text(&ctx.kit.path(cfg::FILE), &toml::to_string(&ctx.cfg)?)?;
        ctx.ok(format!("{} обновлён", cfg::FILE));
    }
    Ok(())
}

fn check(ctx: &Ctx) -> Result<()> {
    println!("Проверка среды:");
    let checks = verify::run(ctx);
    for (i, c) in checks.iter().enumerate() {
        let mark = if c.info { "info" } else if c.ok { " ok " } else { "FAIL" };
        println!("{:>3}. [{mark}] {}: {}", i + 1, c.what, c.detail);
        if !c.hint.is_empty() { println!("           → {}", c.hint); }
    }
    let (p, f) = verify::summary(&checks);
    let path = verify::report(ctx, &checks)?;
    println!();
    println!("Пройдено {p}, провалено {f}. Отчёт: {}", path.display());
    anyhow::ensure!(f == 0, "проверка не пройдена");
    Ok(())
}
```

- [ ] **Step 1: Rewrite `pack.sh` as an assembler**

```sh
#!/bin/sh
# Assemble the two kits from already built parts: the image archive and the
# installer binaries come from CI (or from a local build), nothing is compiled
# here. Keeps the laptop out of the loop: it has neither the memory for the
# image nor a reason to carry a Rust toolchain.
#
#   ./pack.sh <dev1c-image.tar.gz> <dir with dev1c-setup and dev1c-setup.exe>
#
# Output: dist/dev1c-kit (the administrator's kit) and dist/1c-connect (the
# developer's, minus 1c-connect.exe until it exists).
set -eu

DIR=$(cd "$(dirname "$0")" && pwd)
cd "$DIR"
IMAGE_TAR=${1:?path to dev1c-image.tar.gz}
BIN_DIR=${2:?directory with the dev1c-setup binaries}
OUT=${OUT_DIR:-dist}

KIT="$OUT/dev1c-kit"
CONNECT="$OUT/1c-connect"
rm -rf "$KIT" "$CONNECT"
mkdir -p "$KIT" "$CONNECT"

cp "$IMAGE_TAR" "$KIT/dev1c-image.tar.gz"
for b in dev1c-setup dev1c-setup.exe; do
    [ -f "$BIN_DIR/$b" ] && cp "$BIN_DIR/$b" "$KIT/"
done
chmod +x "$KIT/dev1c-setup" 2>/dev/null || true
cp setup/dev1c-setup/dev1c.example.toml "$KIT/dev1c.toml"

# The developer's kit: mcp-1c for the machine with the platform, the same
# release the image was designed against. Pinned here, not in the Dockerfile:
# the image no longer carries mcp-1c.
MCP_1C_VERSION=v1.22.3
for f in mcp-1c-windows-amd64.exe MCP_HTTPService.cfe; do
    curl -fsSL "https://github.com/feenlace/mcp-1c/releases/download/$MCP_1C_VERSION/$f" -o "$CONNECT/$f"
done

# Checksums by the installer itself, so the customer verifies with the same code.
SETUP="$KIT/dev1c-setup"
[ -x "$SETUP" ] || SETUP="$KIT/dev1c-setup.exe"
"$SETUP" --kit "$KIT" checksums >/dev/null
"$SETUP" --kit "$CONNECT" checksums >/dev/null

echo "Kits ready in $OUT:"
du -sh "$KIT" "$CONNECT"
```
