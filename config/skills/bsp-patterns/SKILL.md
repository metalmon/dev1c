# /bsp-patterns — Паттерны работы с БСП/SSL

Справочник паттернов для работы с Библиотекой Стандартных Подсистем.

## Принцип

**ВСЕГДА проверяй есть ли решение в БСП прежде чем писать свой код.**

## Workflow поиска

1. `rg -i "<ключевые слова>" CommonModules/` по выгрузке конфигурации — БСП
   лежит там же, где и остальной код проекта
2. Состав модуля и его экспортных процедур — `get_object_structure` сервера
   `1c` (живая база) или `metadata` сервера `bsl-analyzer`
3. Использование паттерна БСП если найден
4. Только затем свой код — с документированием почему БСП не подошла

Ниже ключевые слова для поиска; в примерах `rg` по каталогу выгрузки.

## Ключевые модули БСП

| Модуль | Назначение |
|--------|-----------|
| ОбщегоНазначения | Утилиты: массивы, структуры, строки, реквизиты |
| ОбщегоНазначенияКлиентСервер | Клиент-серверные утилиты |
| СтроковыеФункцииКлиентСервер | Работа со строками |
| Пользователи | Пользователи, роли, права доступа |
| РаботаСФайлами | Файловое хранилище и вложения |
| УправлениеПечатью | Печатные формы |
| ДлительныеОперации | Фоновые задания с прогрессом |
| ВерсионированиеОбъектов | История изменений объектов |
| РаботаСПочтовымиСообщениями | Отправка email |
| ДополнительныеОтчетыИОбработки | Регистрация внешних обработок |

## Типовые паттерны

### Пользователи и права
```
rg "Пользователи\.(ТекущийПользователь|РолиДоступны|ЭтоПолноправныйПользователь)" CommonModules/
rg "ПравоДоступа\(" CommonModules/
```

### Работа с файлами
```
rg "РаботаСФайлами\.(ДобавитьФайл|ДвоичныеДанныеФайла|ПрисоединенныеФайлы)" CommonModules/
rg "ПоместитьВоВременноеХранилище" CommonModules/
```

### Печатные формы
```
rg "УправлениеПечатью\.(ДобавитьКомандуПечати|СформироватьПечатнуюФорму|МакетПечатнойФормы)" CommonModules/
rg "Процедура ДобавитьКомандыПечати" -g "*.bsl"
```

### Фоновые задания
```
rg "ДлительныеОперации\.(ВыполнитьВФоне|СообщитьПрогресс|ВыполнитьПроцедуру)" CommonModules/
rg "ДлительныеОперации\.ПараметрыВыполненияВФоне" CommonModules/
```

### Версионирование
```
rg "ВерсионированиеОбъектов\.(ЗаписатьВерсиюОбъекта|ВключитьВерсионирование)" CommonModules/
rg "ВерсииОбъектов" -g "*.bsl"
```

### Email
```
rg "РаботаСПочтовымиСообщениями\.ОтправитьПочтовоеСообщение" CommonModules/
rg "ОтправкаПисем|СистемнаяУчетнаяЗапись" CommonModules/
```

## Помни

БСП — это первое место для поиска стандартных функций. Писать свой код когда БСП имеет решение — это технический долг.
