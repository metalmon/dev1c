# /1c-help-mcp — Справка по платформе 1С

Справка по платформе отдаётся двумя MCP-серверами, которые уже подключены в
редакторе. Платформа 1С для них не нужна, сеть тоже.

## Инструменты

| Сервер | Инструмент | Для чего |
|---|---|---|
| `bsl-reference` | `syntax_help` | точная карточка типа, метода, свойства или глобальной функции: сигнатура, параметры, возвращаемое значение |
| `bsl-reference` | `search` с `action=find_docs` | поиск по встроенному каталогу платформы, когда точное имя неизвестно |
| `bsl-reference` | `search` с `action=list_platform` | перечисление типов и членов каталога |
| `1c` | `bsl_syntax_help` | справка по 180 встроенным функциям, методам типов и паттернам BSL — короче и с примерами |

`1c` — это `mcp-1c`, он же читает живую базу (`get_metadata_tree`,
`get_object_structure`, `execute_query`, `get_event_log`). Если база не
настроена, его инструменты отвечают ошибкой подключения; справка тогда идёт
через `bsl-reference`.

## Когда использовать

- Нужна сигнатура метода или функции платформы
- Нужен синтаксис конструкции языка
- Нужны примеры использования API
- Поиск встроенных функций

## Когда НЕ использовать

- Функции БСП → `/bsp-patterns`
- Код проекта → `rg` по выгрузке, диагностики `bsl-analyzer`
- Метаданные живой базы → `get_metadata_tree`, `get_object_structure` сервера `1c`

## Примеры

```
syntax_help(name="СтрРазделить")                    # глобальная функция
syntax_help(type_name="ТаблицаЗначений", name="Свернуть")  # метод типа
search(action="find_docs", query="HTTP соединение")  # по смыслу
bsl_syntax_help(query="работа с файлами")           # с примерами кода
```

## Workflow

1. Точное имя известно → `syntax_help`
2. Имя неизвестно → `search(find_docs)`, затем `syntax_help` по найденному
3. Написать код
4. Проверить диагностиками `bsl-analyzer` (он же LSP в редакторе)
