# Эта среда

Debian в контейнере, графическая сессия по RDP, **интернета нет**. Платформа 1С
в образ не входит.

Прежде чем сказать «такого инструмента здесь нет», проверь: `command -v имя`.

## Чем запускать код на языке 1С

`oscript` — OneScript 2.2, независимая реализация языка 1С на .NET. Работает на
Linux, платформа 1С ему не нужна:

```
oscript скрипт.os
```

Это **не** JScript и **не** Node.js: Windows Script Host, `cscript` и wine здесь
ни при чём и не требуются. Пакеты OneScript ставятся через `opm` (только из
локального кеша, сеть закрыта).

Расширения в экосистеме 1С ровно такие:

| Расширение | Что это |
|---|---|
| `.os` | скрипт OneScript — так называй файлы, которые запускаешь через `oscript` |
| `.bsl` | модуль конфигурации: выгрузка через конфигуратор или EDT |

Других не выдумывай. Редактор определяет язык по расширению, поэтому файл с
придуманным расширением остаётся без подсветки, подсказок и анализатора — хотя
`oscript` его и запустит.

## Остальные инструменты

| Для чего | Чем |
|---|---|
| справочник платформы 1С: синтаксис, методы, типы | MCP `bsl-reference` — спрашивай его, а не предполагай |
| подсказки и диагностика по `.bsl` | `bsl-analyzer` как LSP, уже подключён |
| скрипты | `pwsh` (PowerShell 7), `python3`, `oscript` |
| git и его сервер | `git`, `tea` (CLI к локальному Gitea, вход уже настроен) |
| поиск и обработка | `rg`, `fd`, `jq`, `xmlstarlet`, `xmllint` |

Нет и не будет: `node`, `npm`, `cscript`, wine, выхода в интернет.

## Шум в выводе терминала

Строка вида

```
/bin/sh: 1: Cannot set tty process group (No such process)
```

к результату команды отношения не имеет. Это предупреждение оболочки о
управлении задачами внутри контейнера, где нет обычного init. Команда при этом
выполняется. Не пытайся её «исправить» и не считай признаком отказа — смотри на
код возврата и на остальной вывод.

## Платформа 1С

Конфигуратор, `1cv8` и `vanessa-runner` живут на машине разработчика, а не
здесь. Доступ к ним — только через обратный SSH-туннель, и только если он
поднят. Если туннеля нет, честно скажи, что операция требует платформы, вместо
того чтобы искать обходной путь.
