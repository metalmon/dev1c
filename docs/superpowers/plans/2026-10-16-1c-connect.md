# 1c-connect Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The developer's program `1c-connect`: installs the `mcp-1c` extension into a base, raises the reverse tunnel into the environment with an embedded SSH client, and serves `mcp-1c` and the base's web client to the container over it — nothing installed on the 1C machine.

**Architecture:** A third crate in the `setup/` workspace. `cfg.rs` reads `1c-connect.toml`; `tunnel.rs` keeps one SSH session (`russh`, password, host key pinned in the kit) with two remote forwards, `777N` and `779N`; `bridge.rs` turns each forwarded channel into either a `mcp-1c.exe` process on stdio or a TCP connection to the local web server; `ops_host.rs` wraps it all as operations with `check`. The CI proves the tunnel against the real image: `1c-connect` (Linux build) forwards into the installed container and `nc -z` inside confirms.

**Tech Stack:** Rust 2021, `common` crate (operations, kit, checksums, events), `russh` 0.64 (`ring` feature), `tokio` (rt-multi-thread, net, process, io-util, time, sync), `clap`, `serde`, `toml`, `anyhow`, `reqwest` blocking for the HTTP checks.

**Spec:** `docs/superpowers/specs/2026-10-16-setup-binaries-design.md`, sections «1c-connect», «Хостовый бинарь», «Что меняется в образе» (done by the previous plan).

## Global Constraints

- User-facing strings and `1c-connect.toml` in Russian; code comments, commit messages and README in English.
- Ports from the workstation name only: `devN` → `777N` (mcp-1c), `778N` (vrunner-mcp, reserved, not served in this plan), `779N` (web client). Nothing configurable.
- Nothing installed on the 1C machine: no service, no autostart, no registry, no listening port on the host. The only files are the kit's.
- Password SSH as `dev`; the host key is remembered in `<kit>/known_hosts` on first connect and must match afterwards.
- The tunnel lives while `1c-connect connect` (or the window, later) runs. Reconnect with backoff on drop; never silently stop.
- `check` facts from the base up: platform → kit → extension/publication → SSH → forwards → bridge. Report in `last-check.txt`, no secrets in it.
- Commits use `GIT_AUTHOR_*`/`GIT_COMMITTER_*` = `OktaPlus <oktacoder@gmail.com>` exported in the same shell call, message from a file for multi-line bodies, ending with `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>`.
- `cargo test`/`cargo build` of these crates are light and may run locally; the image and the tunnel proof run in CI.

## Review Focus

1. **Wrong password or wrong server:** `connect` must say which (auth refused vs no route/timeout) in Russian with the field to fix, and `check` must report the same fact, never hang. Test in Task 3 (error mapping).
2. **Port already taken on the server (another developer uses `dev1`):** sshd refuses `tcpip-forward`; the message must name the port and the likely cause («у кого-то ещё поднят туннель dev1»), and the program must not keep retrying that forever as if it were a network drop. Test in Task 3 (forward refusal is terminal, not a reconnect).
3. **Host key changed (environment reinstalled):** connect must refuse with «отпечаток сервера изменился» and tell how to reset (`uninstall` or delete `known_hosts`), not accept silently. Test in Task 3 (known_hosts mismatch).
4. **`mcp-1c.exe` exits at once (bad base URL, wrong credentials):** the forwarded channel must close cleanly and the bridge must log the process's stderr tail, so Zed shows "server stopped" and `check` shows why. Test in Task 4 (bridge with a child that exits immediately).
5. **Web publication missing while the tunnel is up:** forward `779N` lands on nothing; the browser gets connection refused inside, which looks like a tunnel fault. `check` must state «публикация не отвечает» as its own fact before the tunnel ones. Test in Task 5 (`check` ordering with a dead web port).

```rust
//! One SSH session into the environment with remote forwards. Password as
//! `dev`, the host key pinned in the kit after the first connect. Forwarded
//! channels are handed to whoever registered for the port (bridge.rs); here
//! they are only accepted.

use anyhow::{Context, Result};
use russh::client::{self, Handle, Handler, Msg};
use russh::keys::{HashAlg, PublicKeyOrCertificate};
use russh::{Channel, ChannelOpenHandle};
use std::path::{Path, PathBuf};
use std::sync::Arc;
use tokio::sync::mpsc;

/// What a forwarded connection looks like to the bridge: the port the server
/// accepted it on, and the channel to speak through.
pub struct Incoming {
    pub port: u16,
    pub channel: Channel<Msg>,
}

#[derive(Debug)]
pub enum TunnelError {
    Auth,
    HostKeyChanged { old: String, new: String },
    Forward(u16),
    Net(String),
}

impl std::fmt::Display for TunnelError {
    fn fmt(&self, f: &mut std::fmt::Formatter<'_>) -> std::fmt::Result {
        match self {
            TunnelError::Auth => write!(f, "сервер не принял пароль учётки dev — проверьте server и password в 1c-connect.toml"),
            TunnelError::HostKeyChanged { old, new } => write!(f, "отпечаток сервера изменился: был {old}, стал {new}. Если среду переустанавливали — удалите known_hosts из комплекта (или 1c-connect uninstall) и подключитесь заново"),
            TunnelError::Forward(p) => write!(f, "сервер отказал в пробросе порта {p}: у кого-то ещё поднят туннель этого рабочего места, или workstation в 1c-connect.toml не ваш"),
            TunnelError::Net(e) => write!(f, "нет связи с сервером: {e} — проверьте адрес и порт в 1c-connect.toml и что среда запущена"),
        }
    }
}
impl std::error::Error for TunnelError {}

pub struct ForwardHandler {
    server: String,
    known_hosts: PathBuf,
    incoming: mpsc::UnboundedSender<Incoming>,
}

impl Handler for ForwardHandler {
    type Error = anyhow::Error;

    async fn check_server_key(&mut self, key: &PublicKeyOrCertificate) -> Result<bool> {
        let PublicKeyOrCertificate::PublicKey(pk) = key else { anyhow::bail!("сервер предъявил сертификат, а не ключ") };
        let line = format!("{} {}", self.server, pk.to_openssh().context("ключ хоста")?);
        let fp = pk.fingerprint(HashAlg::Sha256).to_string();
        match std::fs::read_to_string(&self.known_hosts) {
            Ok(text) => {
                let known = text.lines().find(|l| l.starts_with(&format!("{} ", self.server)));
                match known {
                    Some(k) if k.trim() == line.trim() => Ok(true),
                    Some(k) => {
                        let old = k.split_whitespace().nth(2).unwrap_or("?").chars().take(16).collect::<String>() + "…";
                        Err(TunnelError::HostKeyChanged { old, new: fp }.into())
                    }
                    // Known file, unknown server: remember it.
                    None => { common::kit::write_text(&self.known_hosts, &(text + &line + "\n"))?; Ok(true) }
                }
            }
            // First connect: remember the key (accept-new).
            Err(_) => { common::kit::write_text(&self.known_hosts, &(line + "\n"))?; Ok(true) }
        }
    }

    async fn server_channel_open_forwarded_tcpip(
        &mut self,
        channel: Channel<Msg>,
        _connected_address: &str,
        connected_port: u32,
        _originator_address: &str,
        _originator_port: u32,
        reply: ChannelOpenHandle,
        _session: &mut client::Session,
    ) -> Result<()> {
        reply.accept().await;
        let _ = self.incoming.send(Incoming { port: connected_port as u16, channel });
        Ok(())
    }
}

pub struct Tunnel {
    pub handle: Handle<ForwardHandler>,
    pub incoming: mpsc::UnboundedReceiver<Incoming>,
}

impl Tunnel {
    /// Connect, authenticate, request every forward. Any failure is one of
    /// `TunnelError`, with the text the person needs.
    pub async fn connect(server: &str, password: &str, known_hosts: &Path, forwards: &[u16]) -> Result<Tunnel> {
        let config = Arc::new(client::Config {
            keepalive_interval: Some(std::time::Duration::from_secs(30)),
            inactivity_timeout: Some(std::time::Duration::from_secs(600)),
            ..Default::default()
        });
        let (tx, rx) = mpsc::unbounded_channel();
        let handler = ForwardHandler { server: server.to_string(), known_hosts: known_hosts.to_path_buf(), incoming: tx };
        let mut handle = tokio::time::timeout(std::time::Duration::from_secs(15), client::connect(config, server, handler))
            .await
            .map_err(|_| TunnelError::Net("тайм-аут подключения".into()))?
            .map_err(|e| match e.downcast_ref::<TunnelError>() {
                Some(TunnelError::HostKeyChanged { old, new }) => TunnelError::HostKeyChanged { old: old.clone(), new: new.clone() },
                _ => TunnelError::Net(e.to_string()),
            })?;
        let auth = handle.authenticate_password("dev", password).await.map_err(|e| TunnelError::Net(e.to_string()))?;
        if !auth.success() {
            return Err(TunnelError::Auth.into());
        }
        for &p in forwards {
            let ok = handle.tcpip_forward("localhost", p as u32).await.map_err(|e| TunnelError::Net(e.to_string()))?;
            if !ok {
                return Err(TunnelError::Forward(p).into());
            }
        }
        Ok(Tunnel { handle, incoming: rx })
    }
}
```

```rust
pub fn render(example: &str, value: impl Fn(&str, &str) -> Option<String>) -> String {
    let mut section = String::new();
    let mut out = String::new();
    for line in example.lines() {
        let t = line.trim();
        if t.starts_with('[') && t.ends_with(']') {
            section = t.to_string();
            out.push_str(line);
        } else if let Some((key, _)) = t.split_once(" = ").filter(|_| !t.starts_with('#')) {
            match value(&section, key) {
                Some(v) => out.push_str(&format!("{key} = {v}")),
                None => out.push_str(line),
            }
        } else {
            out.push_str(line);
        }
        out.push('\n');
    }
    out
}
```

```rust
pub struct Cfg {

}

#[derive(Debug, Clone, PartialEq, Serialize, Deserialize)]
#[serde(default, deny_unknown_fields)]
pub struct Host {
    pub server: String,
    pub password: String,
    pub workstation: String,
    pub base_path: String,
    pub db_user: String,
    pub db_password: String,
    pub base_url: String,
    pub dump: String,
}

impl Default for Host {
    fn default() -> Self {
        Self {
            server: "192.168.1.10:3393".into(),
            password: "dev".into(),
            workstation: "dev1".into(),
            base_path: "C:\\Bases\\Buh".into(),
            db_user: "Администратор".into(),
            db_password: String::new(),
            base_url: "http://localhost/Buh/hs/mcp-1c".into(),
            dump: String::new(),
        }
    }
}

impl Default for Cfg {

    }

pub struct Ports {
    pub mcp: u16,
    pub vrunner: u16,
    pub web: u16,
}

impl Cfg {
    pub fn load(kit: &Kit) -> Result<Cfg> {
        let p = kit.path(FILE);
        if !p.exists() {
            return Ok(Cfg::default());
        }
        let text = std::fs::read_to_string(&p).with_context(|| format!("не прочитать {}", p.display()))?;
        let cfg: Cfg = toml::from_str(&text).with_context(|| format!("{FILE}: ошибка в файле параметров"))?;
        cfg.validate()?;
        Ok(cfg)
    }

    fn number(&self) -> Option<u16> {

        let before_hs = path.split("/hs/").next().unwrap_or("/");
        format!("{}/", before_hs.trim_end_matches('/'))
    }
```

```rust
pub fn retry_delay(attempt: u32) -> std::time::Duration {
    std::time::Duration::from_secs((2u64 << attempt.min(5)).min(60))
}

/// Wrong password, changed key, refused port: retrying would only repeat the
/// same answer — the person has to act. A dropped connection is retried.
pub fn is_terminal(e: &TunnelError) -> bool {
    !matches!(e, TunnelError::Net(_))
}

/// Держит туннель, пока его не остановят: переподключается после обрыва,
/// останавливается на ошибке, которую надо чинить человеку. Каждое
/// проброшенное соединение отдаёт `serve`.
pub async fn run(
    cfg: &crate::cfg::Cfg,
    known_hosts: PathBuf,
    on_event: impl Fn(common::Event),
    serve: impl Fn(Incoming) + Send + Sync + 'static,
    stop: tokio::sync::watch::Receiver<bool>,
) -> Result<()> {
    let serve = Arc::new(serve);
    let ports = cfg.ports();
    let mut attempt = 0u32;
    loop {
        if *stop.borrow() { return Ok(()); }
        match Tunnel::connect(&cfg.host.server, &cfg.host.password, &known_hosts, &[ports.mcp, ports.web]).await {
            Ok(mut t) => {
                attempt = 0;
                on_event(common::Event::Ok(format!("туннель поднят: {} → порты {} и {}", cfg.host.server, ports.mcp, ports.web)));
                let mut stop = stop.clone();
                loop {
                    tokio::select! {
                        inc = t.incoming.recv() => match inc {
                            Some(inc) => serve(inc),
                            None => break, // session gone
                        },
                        _ = stop.changed() => { let _ = t.handle.disconnect(russh::Disconnect::ByApplication, "", "").await; return Ok(()); }
                    }
                }
                on_event(common::Event::Warn("связь с сервером оборвалась — переподключаюсь".into()));
            }
            Err(e) => {
                let te = e.downcast_ref::<TunnelError>();
                if te.is_some_and(is_terminal) {
                    return Err(e);
                }
                on_event(common::Event::Warn(format!("{e}; повтор через {} с", retry_delay(attempt).as_secs())));
            }
        }
        tokio::time::sleep(retry_delay(attempt)).await;
        attempt += 1;
    }
}
```

```rust
//! What answers on the other side of a forwarded channel: for 777N, a fresh
//! mcp-1c process on stdio; for 779N, the local web server. Nothing listens
//! on this machine — the channel is the connection.

use std::process::Stdio;
use tokio::io::{AsyncRead, AsyncReadExt, AsyncWrite, AsyncWriteExt};

pub async fn pipe_process<S>(stream: S, mut cmd: tokio::process::Command, on_exit: impl FnOnce(i32, String))
where
    S: AsyncRead + AsyncWrite + Unpin + Send + 'static,
{
    cmd.stdin(Stdio::piped()).stdout(Stdio::piped()).stderr(Stdio::piped());
    #[cfg(windows)]
    {
        const CREATE_NO_WINDOW: u32 = 0x0800_0000;
        cmd.creation_flags(CREATE_NO_WINDOW);
    }
    let mut child = match cmd.spawn() {
        Ok(c) => c,
        Err(e) => { on_exit(-1, format!("не удалось запустить: {e}")); return; }
    };
    let mut stdin = child.stdin.take().unwrap();
    let mut stdout = child.stdout.take().unwrap();
    let mut stderr = child.stderr.take().unwrap();
    let (mut sr, mut sw) = tokio::io::split(stream);
    let to_child = tokio::spawn(async move { let _ = tokio::io::copy(&mut sr, &mut stdin).await; });
    let from_child = tokio::spawn(async move {
        let _ = tokio::io::copy(&mut stdout, &mut sw).await;
        let _ = sw.shutdown().await;
    });
    let err_tail = tokio::spawn(async move {
        let mut s = String::new();
        let _ = stderr.read_to_string(&mut s).await;
        s.lines().rev().take(5).collect::<Vec<_>>().into_iter().rev().collect::<Vec<_>>().join("\n")
    });
    let status = child.wait().await;
    let _ = from_child.await;
    to_child.abort();
    let tail = err_tail.await.unwrap_or_default();
    on_exit(status.map(|s| s.code().unwrap_or(-1)).unwrap_or(-1), tail);
}

pub async fn pipe_tcp<S>(stream: S, port: u16)
where
    S: AsyncRead + AsyncWrite + Unpin + Send + 'static,
{
    let Ok(mut tcp) = tokio::net::TcpStream::connect(("127.0.0.1", port)).await else { return };
    let mut stream = stream;
    let _ = tokio::io::copy_bidirectional(&mut stream, &mut tcp).await;
}
```

```rust
/// `1cv8.exe`: the newest version under the standard roots.
pub fn find_1cv8() -> Option<std::path::PathBuf> {
    let roots = ["C:\\Program Files\\1cv8", "C:\\Program Files (x86)\\1cv8"];
    let mut found: Vec<std::path::PathBuf> = roots
        .iter()
        .filter_map(|r| std::fs::read_dir(r).ok())
        .flatten()
        .filter_map(|e| e.ok())

        .filter(|p| p.exists())
        .collect();
    found.sort();
    found.pop()
}

            ));
        }
        Ok(())
    }
    fn revert(&self, ctx: &Ctx, _level: CleanLevel) -> Option<Vec<Action>> {
        Some(vec![
            Action::new(format!("1cv8 DESIGNER /F {} /DeleteCfg -Extension MCP_HTTPService (публикацию не трогаем)", ctx.cfg.host.base_path)),
            Action::new("удалить known_hosts из комплекта"),
        ])
    }
    fn revert_apply(&self, ctx: &Ctx, _level: CleanLevel) -> Result<()> {
        let Some(v8) = find_1cv8() else { anyhow::bail!("1cv8.exe не найден") };
        let ib = if ctx.cfg.host.base_path.contains('\\') && !ctx.cfg.host.base_path.contains(':') {
            format!("/S{}", ctx.cfg.host.base_path)
        } else {
            format!("/F{}", ctx.cfg.host.base_path)
        };
        let mut args = vec!["DESIGNER", &ib, "/DisableStartupDialogs", "/DeleteCfg", "-Extension", "MCP_HTTPService"];
        let n = format!("/N{}", ctx.cfg.host.db_user);
        let p = format!("/P{}", ctx.cfg.host.db_password);
        args.push(&n);
        args.push(&p);
        let o = docker::exec(ctx, &v8.to_string_lossy(), &args)?;
        anyhow::ensure!(o.ok(), "конфигуратор не снял расширение: {}", o.tail(3).join(" "));
        let _ = std::fs::remove_file(ctx.kit.path("known_hosts"));
        ctx.ok("расширение снято, отпечаток сервера забыт");
        Ok(())
    }
}

pub fn host() -> Vec<Box<dyn Op<Ctx>>> {
    vec![Box::new(Env), Box::new(Extension)]
}
```

```rust
Cmd::Connect => {
    let rt = tokio::runtime::Runtime::new()?;
    rt.block_on(async {
        let (stop_tx, stop_rx) = tokio::sync::watch::channel(false);
        let ctrl = tokio::spawn(async move { let _ = tokio::signal::ctrl_c().await; let _ = stop_tx.send(true); });
        let cfg = ctx.cfg.clone();
        let kit = ctx.kit.clone();
        let ports = cfg.ports();
        let web_port = cfg.web_port();
        let sink = ctx.sink.clone();
        let serve = move |inc: one_c_connect::tunnel::Incoming| {
            let stream = inc.channel.into_stream();
            if inc.port == ports.mcp {
                let cmd = one_c_connect::bridge::mcp_command(&cfg, &kit);
                let sink = sink.clone();
                tokio::spawn(one_c_connect::bridge::pipe_process(stream, cmd, move |code, err| {
                    if code != 0 { sink(common::Event::Warn(format!("mcp-1c завершился с кодом {code}: {err}"))); }
                }));
            } else if inc.port == ports.web {
                tokio::spawn(one_c_connect::bridge::pipe_tcp(stream, web_port));
            }
        };
        let sink2 = ctx.sink.clone();
        println!("Подключаюсь к {} как {}; порты {} (mcp-1c) и {} (веб-клиент). Ctrl+C — отключиться.", ctx.cfg.host.server, ctx.cfg.host.workstation, ports.mcp, ports.web);
        let r = one_c_connect::tunnel::run(&ctx.cfg, ctx.kit.path("known_hosts"), move |e| sink2(e), serve, stop_rx).await;
        ctrl.abort();
        r
    })?;
    println!("Отключено.");
}
```
